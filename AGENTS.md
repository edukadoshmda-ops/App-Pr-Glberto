# Supervisor do Projeto

## Missão
Este projeto deve ser executado com uma arquitetura de agentes especializados e supervisão central.

## Fluxo de trabalho
1. O agente supervisor coordena todas as tarefas do projeto.
2. Cada agente especializado entrega um módulo funcional.
3. O agente de revisão analisa qualidade, consistência, UX, responsividade e desempenho.
4. Só após aprovação do agente supervisor a entrega final é considerada concluída.

## Agentes obrigatórios
- Dashboard Profissional
- Audio Book
- Play Books
- Artigos
- Vídeos
- Projetos
- Relatórios Profissionais
- Revisor / Validador

## Critérios de aprovação
- Layout moderno e elegante
- Cores consistentes com identidade visual
- Navegação clara e profissional
- Feedback visual em todos os módulos
- Ajustes responsivos para desktop e mobile
- Sem erros visuais ou de lógica

## Regra final
O agente supervisor deve aprovar a entrega somente quando todos os módulos estiverem coesos, funcionais e alinhados ao briefing.

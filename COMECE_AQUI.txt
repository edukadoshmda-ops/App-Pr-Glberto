💡 TIPS & TRICKS

Para Customizar Cores:
  Edite as variáveis CSS em style.css:
  :root {
    --primary: #4d7a63;
    --gold: #D4AF37;
    /* etc... */
  }

Para Adicionar Animações:
  Use @keyframes em style.css
  Aplique com animation: nomeAnimação duration timing;

Para Novos Módulos:
  1. Copie um HTML existente
  2. Mude o conteúdo
  3. Adicione link ao sidebar
  4. Teste responsividade

Para Mudar Fontes:
  Edite em style.css onde diz:
  font-family: 'Inter', sans-serif;

🆘 TROUBLESHOOTING

Problema: Login não funciona
Solução: Verifique se localStorage está ativado no navegador

Problema: Animações lentas
Solução: Atualize o navegador, desative extensões

Problema: Página não carrega
Solução: Limpe cache (Ctrl+Shift+Delete), reabra

Problema: Menu não funciona
Solução: Verifique console (F12), veja se JS está ativado

Veja mais em: GUIA_USO.md

## 🔐 AUTENTICAÇÃO

### Sistema
- localStorage para sessão
- Redirecionamento automático
- Proteção de páginas
- Qualquer email/senha funciona (protótipo)

### Fluxo
1. Usuário acessa login.html
2. Digita email e senha (qualquer valor)
3. Clica ENTRAR
4. É redirecionado para index.html
5. Sessionagem mantida até limpar cache

## ✨ ANIMAÇÕES IMPLEMENTADAS

### Na Entrada das Páginas
- Headers fazem slide down
- Cards fazem fade in up
- Delays escalonados (0.1s, 0.2s, 0.3s...)

### No Hover
- Cards elevam com sombra
- Botões fazem transform Y
- Menu items têm gradient overlay
- Links mudam cor para dourado

### No Click
- Botões comprimem (translateY -1px)
- Checkbox faz scale
- Feedback visual imediato
